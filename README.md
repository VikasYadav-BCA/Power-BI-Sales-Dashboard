# Power BI Sales Dashboard

## About the Project
This project is an interactive Sales Dashboard developed using Microsoft Power BI. It helps analyze sales performance and understand business insights through visualizations.

## Project Objectives
- Analyze total sales and revenue.
- Identify top-performing products.
- Track sales performance.
- Understand business trends.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Key Features
- Interactive Dashboard
- KPI Cards
- Sales Charts
- Data Filters and Slicers
- Business Insights

## Project Files
- `.pbix` – Power BI Dashboard
- `.xlsx` – Dataset
- `.png` – Dashboard Screenshot
